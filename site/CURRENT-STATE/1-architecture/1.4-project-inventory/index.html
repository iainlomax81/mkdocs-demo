Solution Overview

Key Technologies: - Log4Net 1.2.10 - StructureMap 2.5 - ASP.NET Forms Authentication - ASP.NET Membership Provider - Janrain Authentication API - PayPal Standard Payments API

Project Dependencies:
✅ NONE - Infrastructure layer is the foundation with no upward dependencies

Key Files: - Authentication/ - Forms Auth, Membership, Janrain implementations - Configuration/ - Application settings management - Domain/ - EntityBase, ValueObjectBase, AggregateRoot, DomainEvents - Email/ - SMTP and logging email services - Logging/ - Log4Net adapter - Payments/ - PayPal payment service - Querying/ - Query abstraction - UnitOfWork/ - IUnitOfWork and IRepository interfaces

Dependency Rules

Architectural Layers

Layer Mapping

Architectural Layer Projects Purpose
Presentation Layer UI.Web.MVC, Controllers HTTP handling, view rendering, user input
Business Logic Layer Services, Services.Cache Business workflows, use case orchestration

Layer Responsibilities

Data Access Layer: - Repository implementations - NHibernate ORM configuration - Database session management - Query translation

Infrastructure Layer: - Authentication and authorization - Logging - Configuration - Email services - Payment gateway integration - Domain base classes and abstractions

Migration Considerations

.NET Framework to .NET 6+ Migration Path

Option 1: Incremental Upgrade 1. Upgrade all projects to .NET Framework 4.8 (latest) 2. Migrate to .NET Standard 2.0 for class libraries 3. Migrate to .NET 6+ for web application 4. Migrate class libraries to .NET 6+

Option 2: Direct Migration 1. Directly migrate all projects to .NET 6+ 2. Replace ASP.NET MVC 2 with ASP.NET Core MVC 3. Replace dependencies with modern equivalents

Option 3: Parallel Development 1. Build new .NET 6+ solution alongside legacy 2. Port layer by layer (Infrastructure → Model → Services → Controllers → UI) 3. Cutover when feature parity achieved

Recommended: Option 1 (Incremental) - Lower risk, gradual migration
